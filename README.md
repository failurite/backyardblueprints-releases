# Backyard Blueprints — Releases

Public installer mirror for [Backyard Blueprints](https://backyardblueprints.net), a DIY shed designer for Windows, macOS, iOS, and Android.

Source code is maintained in a private repository. This repo only hosts signed/unsigned release installers for distribution channels (Microsoft Store, direct download, etc.).
